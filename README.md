# Superstore Sales and Profit Analysis Dashboard

## Project Overview

This project is an interactive Sales and Profit Analysis Dashboard created using Tableau as part of an internship Task 4.

The project uses the Superstore Sales Dataset to analyze business performance across different time periods, product categories, regions, customer segments, and shipping modes.

The main objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard.

## Objectives

- Analyze overall Sales, Profit, Quantity, and Orders.
- Understand monthly Sales and Profit trends.
- Compare sales performance across Categories.
- Analyze Profit across Sub-Categories.
- Compare Sales performance across Regions.
- Identify the Top 10 Products based on Sales.
- Analyze Sales by Customer Segment.
- Analyze Sales by Ship Mode.
- Create an interactive Tableau dashboard.
